## 过程教训（sc-lead 2026-11-28 要求记录在此，不进 spec）

**方案增量稿引用批次号前，必须先核该批次是否已合入、以及合入的代码是否真的含那条改动。**

这次的根因就是它：v2 §十 把两项活派给「P4」，写稿时 P4 在飞，落稿时 P4 已合入（`eabb196`）——但两项都没做。若折回时照抄「本批修」，spec 会把两件没做的事写成已完成，验收也就跟着绿了，且没人会再去核。正确做法是**折回时以代码为准逐条核对 v2 的每一条「已修/随批落」断言**，凡不符就按实际写成缺口并标红灯。
