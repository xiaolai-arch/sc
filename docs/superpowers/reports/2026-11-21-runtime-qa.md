## 5. 推荐修复顺序（仅缺陷）

1. **D1 提醒行布局（major）** — 最高优先：默认窗口下用户根本看不到提醒内容。建议让内容列获得最小宽度（如 `min-w-[6rem]` 或把时间+内容放在一行、动作按钮换行/收纳到「更多」），并给行加 `flex-wrap`，避免整行横向溢出。修好后 `e2e/qa-reminder-row.spec.ts` 的 `fixme` 即可移除。
2. **D2 停止后的运行状态（major）** — 停止应显示为「已中断」而非绿色「已完成」，否则用户以为生成完整。让 `runStates` 使用 `run.canceled` 映射到 `interrupted`（或新增 `stopped`）。
3. **D3 延后时间可见性（minor）** — 徽标正文直接显示「已延后 · 10:45」，或今日「最近提醒」按 `postponedTo` 显示。
4. **D5 / D6 重复入口（minor）** — 删除卡片外的冗余按钮，空状态只保留一个主行动。
5. **D7 / D8 文案一致性（cosmetic）** —「最近提醒」排除 `done`；侧栏 tooltip 改为标题/分组而非首条预览。
